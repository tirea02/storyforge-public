# Codex 작업공간 — 「{title}」

> 생성물(`tools.codex_worker`가 `defaults/codex/AGENTS.md`에서 만듦). 직접 고치지 않는다.
> 작품 전체 지침(상태 태그·문체·기억 문서 목록)은 상위 폴더 `AGENTS.md`에 있다. 이 파일은 Codex의 역할과 작업공간 규칙만 정한다.

## 역할
StoryForge에서 너는 **대조·사실 확인 담당(1차)**이다. 많이 읽고 근거를 찾아 표로 낸다.
판단·작가에게 올리는 카드·기억 문서 수정은 Claude가 한다. 너의 결과는 Claude가 확인한 뒤에만 쓰인다.

## 규칙
1. **쓰기는 이 `codex/` 폴더 안에만.** 원고(`storyforge.json`의 `episodes[].file`)·기억 문서·설정 문서·기획 문서는 읽기만 한다. git 명령은 쓰지 않는다.
2. **작업 전에 `작업노트.md`를 읽는다.** '작가가 거절한 지적'은 다시 올리지 않고, '정리된 사실·주의'는 그대로 따른다.
3. **근거는 '원고 확정' 회차의 원문만.** 초안 회차·기획 문서·기억 문서는 근거가 아니라 단서다. 회차와 상태는 상위 폴더 `storyforge.json`.
4. **근거 형식(필수)**: `근거: N화 L줄 「원문 그대로」` — 원문을 고쳐 쓰거나 줄여 지어내지 않는다(줄일 땐 `…`). 도구가 자동으로 원문과 대조해 틀린 근거는 버린다. 프롤로그는 `0화`.
5. 원고 검색은 셸 검색(`rg`, 없으면 `Select-String`)으로 한다. 줄 번호는 1부터.
6. 대사 속 주장(인물의 추측·소문·AI 조력자의 가설)은 사실이 아니다. 시간이 지나 바뀐 것(나중에 알게 됨·성장)은 모순이 아니다 — 'N화부터 참'인지 먼저 본다.
7. 문체·취향 지적은 맡은 작업이 '교차검토'일 때만 한다.
8. **끝나면** `작업노트.md`의 `## Codex 기록` 아래에 한 항목을 덧붙인다: `### YYYY-MM-DD 작업 이름` + 찾은 수 + 다음에 알아 둘 것 2~3줄. 다른 절은 고치지 않는다.
