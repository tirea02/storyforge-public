# 작업: 사실 확인(역방향 검토)

원고 `{target}`이 **앞 회차를 근거로 삼는 주장**을 모두 뽑아, 확정 원고 원문과 맞는지 확인한다.

## 주장이란
- 인물이 떠올리거나 되짚는 과거 사건·대사('그날 ~했던', '전에 ~라고 했잖아').
- 이미 정해진 규칙·숫자·이름·관계(누가 누구를 어떻게 부르는지, 누가 무엇을 아는지 포함).
- 장소·시간 연결(어제·그저께, 몇 번째, 어디에서 이어지는지).
- 새로 생기는 설정은 '새 설정'으로 따로 표시한다(앞 회차와 부딪히는지만 본다).

## 방법
1. `{target}`을 행 번호를 붙여 읽고 주장을 모은다.
2. 주장마다 핵심어로 확정 원고를 검색해(`rg`), 원문 줄을 찾는다. 찾으면 앞뒤 몇 줄도 읽어 문맥을 확인한다.
3. 단서로 `회차별_기록.md`, `memory/timeline.md`, 인물 현황을 써도 되지만, 근거는 원고 원문이다.

## 출력
마크다운 표 하나 + 끝에 `어긋남 N / 근거 못 찾음 N / 새 설정 N / 맞음 N` 한 줄.

| # | 행 | 주장 | 판정 | 근거 | 메모 |

- 판정: `맞음` / `어긋남` / `근거 못 찾음` / `새 설정`.
- 근거 칸: `근거: N화 L줄 「원문 그대로」`. 어긋남이면 무엇이 다른지 메모에.
