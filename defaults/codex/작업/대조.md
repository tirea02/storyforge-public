# 작업: 샘플 대조

초안 `{target}`이 그 앞의 확정 원고 `{against}`와 기억 문서에 맞는지 대조한다.
확정본은 샘플을 쓴 뒤 작가가 고친 판이라, 샘플에 옛 설정이 남아 있을 수 있다.

## 찾을 것
1. 확정본에서 바뀐 이름·사물·숫자·설정이 샘플에 옛것으로 남은 곳.
2. 확정본의 사건·약속·대사와 어긋나는 서술(샘플이 확정본 내용을 다르게 되짚는 곳).
3. 확정본에 새로 생긴 사실을 샘플이 모르는 곳(이어지지 않는 곳).
4. 기억 문서의 [원고 확정]·[설정 확정]과 어긋나는 곳.

문체 지적은 하지 않는다.

## 읽을 것
- `{target}`(행 번호를 붙여 읽는다), `{against}` 전체.
- 단서: `회차별_기록.md`의 `{against_label}` 절, 상위 `HANDOFF.md`에서 `{target_label}`을 언급한 줄.

## 출력
마크다운 표 하나 + 총평 1줄.

| # | 샘플 행 | 어긋남 | 근거 | 제안 |

- 근거 칸: `근거: N화 L줄 「원문 그대로」` (확정본 쪽). 여러 개면 `;`로.
- 제안은 고칠 방향만 짧게(샘플을 다시 쓰지 않는다).
