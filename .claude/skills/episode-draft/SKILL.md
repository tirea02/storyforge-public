# 다음 회차 샘플 작성

`<작품>` = 대상 작품 폴더(작품이 둘 이상이면 작가에게 확인).

## 순서
0. `defaults/작가_작업규칙.md`(공통 작업 규칙)를 따른다. 작품 README '검토 규칙'이 우선.
1. **현재 위치 파악**: `<작품>/README.md`('검토 규칙'), 인물 현황(`storyforge.json`의 `characters`, 있으면), `memory/timeline.md`, `memory/open_loops.md`, 작품 폴더의 전개 메모(있으면), 최근 확정 회차 2개.
1-1. **장소·인물 규칙표**: 장면마다 장소의 규칙(출입 구역·마법 제한 등)과 등장인물의 호칭·말투·아는 것을 인물 문서·설정 대장에서 확인해 짧은 표로 만든다. 원고·설정에 없는 감각·속성(체온 등)은 새로 쓰지 않는다. 장면이 바뀔 때마다 일행 각자의 위치(어디로 갔다가 언제 합류하는지)와 주인공의 기존 일과(다니던 곳 등)도 표에 적는다.
2. **기획(plan)**: 장면 3~5개 표. 이번 화의 작은 보상(발견/성취/개그/관계) 1개 이상, 진전시킬 복선, 새로 정해야 하는 설정(작가 확인 필요로 표시).
3. **기억 묶음**: 기획을 파일로 저장한 뒤 `tools.recall --from-file <기획> --recent 30`.
4. **문체**: `<작품>/style_profile.md` 0번 요약을 그대로 따른다. [시험 중] `defaults/작가_작업규칙.md` §5-1 가이드라인(감정 우선·일상어·리듬·덜 논리적)으로 먼저 쓰고, 앞 회차와의 모순은 5-1 역방향 점검·Codex 사실 확인에서 잡는다. 쓰는 동안 앞 회차 사실을 확인하듯 되짚는 문장·수치를 늘리지 않는다.
5. **작성** 후 `tools.check_episode`로 점검 → 초과 패턴·짧은 단문 몰림·분량(작품의 목표 범위) 수정. 도구가 못 잡는 AI 습관(감정 해설, 같은 판단 반복, 박자 맞추기용 대답)도 다시 읽으며 고친다.
5-1. **역방향 점검(샘플은 항상 — 새로 쓴 글이므로)**: 쓴 원고에서 사실처럼 쓰인 주장을 뽑아 앞 회차 원고 원문을 grep해 대조한다(`episode-review` 4-1과 같음). 대조 결과를 보고에 붙인다.
6. 첫 판을 `NN화_샘플.txt`(초기본, 이후 고치지 않음)로 저장하고 같은 내용으로 `NN화_수정.txt`(작업본)를 만든다. 이후 수정은 `_수정`에만. `storyforge.json`에 `file: NN화_수정.txt`, `initial: NN화_샘플.txt`, `status: "초안"`으로 등록. 작품 폴더에서 git 커밋. 기억 문서에는 ⚠초안으로만 반영하거나 반영하지 않는다.
7. 보고: 기획 표, 분량, 작가 확인이 필요한 새 설정 목록.

## 마무리
- `작업_로그.md`에 이번 작업 요약(한 일 / 작가 확인 필요 / 참고)을 추가 → `tools.dashboard` 갱신 → 작품 폴더 git 커밋.

## 원칙
- 작가가 정하지 않은 큰 설정(이름, 핵심 미스터리의 정답, 세계 규칙)은 확정하지 않는다. 열어 두거나 [인물의 추측]으로. 이름이 필요하면 `〔이름〕` 같은 자리 표시.
- 직전 화와 같은 개그·마무리 반복 금지.
- 샘플은 재료다. 작가가 퇴고한 확정본이 언제나 우선.
