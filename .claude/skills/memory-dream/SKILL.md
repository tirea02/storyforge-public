# 기억 점검 (Dreaming)

회차 확정 때마다 하는 가벼운 점검(episode-confirm 11-1)과 달리, 이 스킬은 **기억 문서 전체를 다시 읽는다**.
배경: 기억은 작업 중에 조금씩 덧붙여지면서 중복·모순·낡은 항목이 쌓인다. 원본(확정 원고)과 다시 대조해 고쳐야 다음 화를 쓸 때 틀린 기억을 믿지 않는다.

## 원칙
- **읽기 전용.** 점검 중에는 기억 문서를 고치지 않는다. 결과는 카드(원본 vs 제안)로 올리고, 작가 판정 뒤에 고친다. 원고는 절대 고치지 않는다.
- 원고가 정본이다. 원고에 없는 것을 사실로 올리지 않는다.
- 시간에 따른 변화(인물이 나중에 알게 됨, 성장)는 모순이 아니다 — 'N화부터 참'인지 먼저 확인한다.
- 판단은 좋은 모델이 한다(기억 쓰기·점검을 싼 모델에 맡기지 않는다).

## 순서
1. **기준 점검**: `.venv/Scripts/python -m tools.memory_audit --project <작품> -o <작품>/reviews/기억점검/<날짜>_장끝.md` — 직전 보고서와 숫자를 비교한다(원문과 맞는 인용 수가 줄었으면 이유를 찾는다).
2. **낡은 표시**(도구가 찾음): 확정 회차의 ⚠, 지난 회차의 '예정·[기획]', 오래된 '기준: N화', 복선 상태 칸.
3. **원문과 다른 인용**(도구가 찾음): '근거 없음'·'다른 화'를 담당 문서부터 본다(개인 문서·인물 현황·복선 → 설정집·설정 대장 → 그 밖). 바꿔 말한 것인지, 없는 대사인지, 회차 표기만 틀렸는지 나눈다.
4. **사람이 읽어야 찾는 것**(도구가 못 찾음) — 담당 문서를 차례로 읽으며:
   - **낡은 '지금'**: 인물 현황·개인 문서의 지금·능력·관계가 최신 확정 회차와 맞는지.
   - **겹침**: 같은 사실이 담당 문서 밖에 길게 적혀 있는지(담당 표 기준). 한 줄 요약·링크로 줄일 후보.
   - **서로 안 맞음**: 설정집·설정 대장·기획 문서·검증 목록이 같은 사실을 다르게 말하는지(폐기된 안이 살아 있는지).
   - **빠짐**: 회차 기록에는 있는데 담당 문서(개인 문서 행적, 복선 진전)에 없는 것.
   - **불필요**: 해결된 질문(검증 목록 → 보관), 회수된 복선의 긴 진전 칸, 끝난 장의 기획.
5. **카드**: 찾은 것마다 카드 한 장 — 문서·줄, 지금 적힌 것, 원고·기록 근거(원문 인용), 제안, 판정 버튼(진짜 오류 / 문제 아님 / 보류). 작품의 모바일 페이지가 있으면 그 방식으로, 없으면 Artifact 카드 페이지.
6. **판정 뒤 반영**: '진짜 오류'만 담당 문서에서 고치고, 다시 1번을 돌려 원문과 맞는 인용이 줄지 않았는지 확인 → 작품 저장소 커밋 → 작업 로그.

## 언제
- 장(에피소드 묶음)이 끝날 때 한 번. 기억 문서가 원고보다 커졌을 때.
- 매 회차 확정 때는 episode-confirm 11-1(도구만, 새로 생긴 것만)로 충분하다.
