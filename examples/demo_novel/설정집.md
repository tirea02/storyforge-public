# 「등대지기 수습일지」 설정집

> 기준: 1화. 태그는 README 운영 규칙.

## 1. 작품 개요
- 가제: 「등대지기 수습일지」 [설정 확정]
- 장르·분위기: 벨 에포크풍 가상 해안 마을의 코즈믹 호러(크툴루 신화풍). 증기 열차·전신·전등의 시대. 정체는 끝까지 흐릿하게 둔다. [설정 확정]
- 시점: 1인칭 주인공 주앙 [원고 확정: 1화]

## 2. 세계
- **[원고 확정: 1화]** 블랙코브 열차는 하루 두 번(아침 일곱 시, 오후 세 시). 마지막 고개를 넘으면 전신주가 끊긴다.
- **[원고 확정: 1화]** 고갯마루 이정표 밑 덧쓴 글씨: "해 질 시 출입 금지!"
- **[원고 확정: 1화]** 등대 전구는 십 년 전에 들였다(그전엔 기름). 옆 벽돌 기관실의 증기 발전기로 돌린다. 점등은 놋쇠 레버.
- **[원고 확정: 1화]** 등대 계단은 맑은 날 백십사 칸. 하그레이브: "그게 맞는 숫자다."
- **[원고 확정: 1화]** 렌즈는 마른 천 → 기름 천 → 마른 천. 순서를 바꾸면 얼룩, 얼룩지면 빛이 흐려진다. "배만 못 보는 게 아니야."
- **[원고 확정: 1화]** 등대의 세 가지 규칙
  1. 해 지기 전에 불을 켤 것.
  2. 안개 낀 날에는 계단을 세지 말 것.
  3. 바다에서 누가 부르거든 대답하지 말 것. 아는 목소리면 더더욱.
- **[원고 확정: 프롤로그]** 안개 낀 날 계단을 세면 하루에 한 칸씩 늘었다(백십오 → 116).
