# 「등대지기 수습일지」 설정집

> 기준: 1화. 태그는 README 운영 규칙.

## 1. 작품 개요
- 가제: 「등대지기 수습일지」 [설정 확정]
- 장르·분위기: 시골 어촌 코즈믹 호러(크툴루 신화풍). 정체는 끝까지 흐릿하게 둔다. [설정 확정]
- 시점: 1인칭 주인공 '나' [원고 확정: 1화]

## 2. 세계
- **[원고 확정: 1화]** 흑포리 버스는 하루 두 대(아침 일곱 시, 오후 세 시). 마지막 고개를 넘으면 휴대폰이 안 터진다.
- **[원고 확정: 1화]** 고갯마루 표지판 밑 덧쓴 글씨: "해 지면 들어오지 마시오."
- **[원고 확정: 1화]** 등대 계단은 맑은 날 백열네 칸. 영감: "그게 맞는 숫자다."
- **[원고 확정: 1화]** 렌즈는 마른 천 → 기름 천 → 마른 천. 순서를 바꾸면 얼룩, 얼룩지면 빛이 흐려진다. "배만 보는 게 아니야."
- **[원고 확정: 1화]** 등대의 세 가지 규칙
  1. 해 지기 전에 불을 켤 것.
  2. 안개 낀 날에는 계단을 세지 말 것.
  3. 바다에서 누가 부르거든 대답하지 말 것. 아는 목소리면 더더욱.
- **[원고 확정: 프롤로그]** 안개 낀 날 계단을 세면 하루에 한 칸씩 늘었다(백열다섯 → 백열여섯).
